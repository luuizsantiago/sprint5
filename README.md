# Painel de anúncios de carros

Aplicativo web feito com Streamlit para explorar um conjunto de dados de anúncios de venda de carros.

## Funcionalidades
- Botão para criar um histograma da quilometragem (`odometer`)
- Botão para criar um gráfico de dispersão de quilometragem x preço

## Tecnologias
Python, pandas, Plotly Express, Streamlit, Render

## Como rodar localmente
pip install -r requirements.txt
streamlit run app.py
